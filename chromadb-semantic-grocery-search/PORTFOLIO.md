## ChromaDB Semantic Grocery Search

Built an interactive semantic-search application using Python, ChromaDB, SentenceTransformers, and Gradio to explore how vector databases retrieve information by meaning rather than exact keyword matching.

Converted grocery descriptions into dense vector embeddings, stored them in a ChromaDB collection configured for cosine-based HNSW retrieval, and implemented natural-language Top-K search, metadata filtering, and persistent local vector storage.

Extended the original coursework exercise into a modular application that separates data ingestion, vector-store management, retrieval logic, and user interaction.

**Technologies:** Python · ChromaDB · SentenceTransformers · Vector Embeddings · HNSW · Cosine Similarity · Semantic Search · Metadata Filtering · Gradio
