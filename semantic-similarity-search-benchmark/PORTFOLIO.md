## Semantic Similarity Search & Embedding Benchmark

Built an educational semantic-search engine from first principles to explore how vector embeddings power modern information retrieval systems.

The project implements Euclidean distance, dot product, vector normalization, cosine similarity, and cosine distance manually before comparing them with vectorized NumPy/SciPy implementations. SentenceTransformer models convert natural-language documents and queries into dense embeddings, which are then ranked using multiple similarity metrics.

Extended the original coursework concept into an interactive benchmark that allows users to compare embedding models, similarity metrics, top-k retrieval behavior, and ambiguous semantic contexts through a Gradio interface.

### Technologies

Python · NumPy · SciPy · PyTorch · Sentence Transformers · Hugging Face · Vector Embeddings · Semantic Search · Cosine Similarity · Gradio
