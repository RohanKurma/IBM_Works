## ChromaDB Semantic Talent Search

Built an employee and talent discovery application using Python, ChromaDB, SentenceTransformers, HNSW indexing, and Gradio.

Converted employee roles, skills, experience, departments, locations, and employment information into searchable semantic profiles. Implemented natural-language vector similarity search and combined it with structured metadata filters such as department, minimum years of experience, location, and employment type.

Extended a coursework prototype into a modular talent-search system with persistent vector storage, configurable embedding models, Top-K retrieval, and an interactive search interface.

**Technologies:** Python · ChromaDB · SentenceTransformers · Vector Embeddings · HNSW · Cosine Similarity · Semantic Search · Metadata Filtering · Gradio
